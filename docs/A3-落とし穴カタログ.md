## 1. 計算と比較がおかしい

| 症状 | 原因 | 直し方 | 章 |
|---|---|---|---|
| `"1" + 2` が `"12"` になる | `+` は、どちらかが文字列なら連結する | 外から来た値は `Number()` で数値にしてから計算する | [04](04-演算子と型変換.md#2--は足し算か連結か) |
| 結果が `NaN` になる | `undefined` や数値でない文字列を計算に使った | 入口で `Number.isNaN` を調べ、おかしければ `throw` する | [04](04-演算子と型変換.md#5-nan-と明示的な変換) |
| 引数を渡し忘れても何も言われず `NaN` | 足りない引数は `undefined` になる | 既定値を書く ・ 中で確かめる | [06](06-関数.md#1-関数を作って呼ぶ) |
| 違う値どうしが等しいと判定される | `==` が型を変換してから比べた | いつも `===` を使う | [04](04-演算子と型変換.md#3--と-) |
| `0.1 + 0.2` が `0.3` にならない | 小数は 2 進数で近似される | お金は円単位の整数で計算する ・ 表示で `toFixed` | [03](03-値と変数.md#3-数値) |
| `7 / 2` が `3.5` になる | 数値は小数を含む 1 種類だけ | 整数にしたいときは `Math.floor` | [03](03-値と変数.md#3-数値) |
| 文字数が見た目より多い | `length` は UTF-16 の単位の数。絵文字は 2 | `[...s].length` | [03](03-値と変数.md#4-文字列) |

## 2. 値が無い

| 症状 | 原因 | 直し方 | 章 |
|---|---|---|---|
| `TypeError: Cannot read properties of undefined (reading 'x')` | 途中のプロパティが `undefined` だった | どこが `undefined` かを調べる。無いことがあるなら `?.` | [03](03-値と変数.md#5-null-と-undefined) |
| `if (count)` で 0 が「無い」扱いになる | `0` ・ `""` も falsy | `count === undefined` のように、何を調べたいかを書く | [04](04-演算子と型変換.md#4-truthy-と-falsy) |
| 既定値を入れたら 0 や `""` が消えた | `\|\|` は falsy をすべて置き換える | `??` を使う | [04](04-演算子と型変換.md#6--と-) |
| 配列の範囲外を読んでもエラーにならない | 無い番号は `undefined` を返す | `length` で範囲を確かめる | [05](05-オブジェクトと配列.md#2-配列) |
| 関数の結果が `undefined` | `return` を書き忘れた ・ アロー関数で `{ }` を付けた | `return` を書く ・ 式 1 つなら `{ }` を外す | [06](06-関数.md#2-関数式とアロー関数) |
| 関数そのものが表示される（`[Function: f]`） | `()` を付けずに関数を渡した | 呼ぶなら `f()` | [06](06-関数.md#4-関数は値) |

## 3. 名前 ・ スコープ ・ this

| 症状 | 原因 | 直し方 | 章 |
|---|---|---|---|
| `ReferenceError: x is not defined` | 名前の書き間違い ・ 大文字と小文字の違い ・ スコープの外 | 綴りと、どの `{ }` の中で作ったかを確かめる | [07](07-スコープとthis.md#1-スコープ) |
| `ReferenceError: Cannot access 'x' before initialization` | `let` ・ `const` を、宣言の行より前で使った | 宣言を上に移す | [07](07-スコープとthis.md#2-var-と巻き上げ) |
| `TypeError: Assignment to constant variable.` | `const` の変数に入れ直した | 入れ直すなら `let` | [03](03-値と変数.md#1-変数を作る) |
| 関数の中の変数が、外から見えてしまう | `let` ・ `const` を付け忘れ、グローバルにできた | 宣言を付ける。モジュールか strict モードにすると、エラーで気づける | [07](07-スコープとthis.md#3-グローバル変数の事故) |
| `this.x` が `undefined` ・ `NaN` | メソッドを取り出して（コールバックとして）呼んだ | `() => obj.m()` ・ `obj.m.bind(obj)` | [07](07-スコープとthis.md#5-this-を失わない書き方) |
| `TypeError: Cannot read properties of undefined (reading 'x')`（クラスの中で） | 同上。クラスは strict なので `this` が `undefined` | 同上 | [08](08-クラスとプロトタイプ.md#5-java--c-のクラスとの違い) |
| ループで作った関数が、全部同じ値を見る | `var` のループ変数は 1 つしかない | `let` にする | [09](09-クロージャ.md#4-ループの中の関数) |
| `ReferenceError: Must call super constructor …` | 子クラスの `constructor` で `super()` より前に `this` を使った | 先頭で `super(…)` を呼ぶ | [08](08-クラスとプロトタイプ.md#3-継承) |

## 4. 配列とオブジェクト

| 症状 | 原因 | 直し方 | 章 |
|---|---|---|---|
| コピーを変えたら、元も変わった | 代入は参照を写すだけ | `{ ...o }` ・ `[...arr]` でコピーする | [05](05-オブジェクトと配列.md#3-参照とコピー) |
| コピーしたのに、中の配列が元と一緒に変わる | `...` のコピーは 1 段目だけ | `structuredClone(o)` | [05](05-オブジェクトと配列.md#3-参照とコピー) |
| 同じ中身なのに `===` が `false` | オブジェクトの `===` は「同じものか」を比べる | 中身を 1 つずつ比べる | [05](05-オブジェクトと配列.md#3-参照とコピー) |
| `[10, 9, 1].sort()` が `[1, 10, 9]` | 引数なしの `sort` は文字列として並べる | `sort((a, b) => a - b)` | [05](05-オブジェクトと配列.md#5-配列のメソッド) |
| 並べ替えたら元の配列まで変わった | `sort` は元の配列を並べ替える | `[...arr].sort(…)` | [05](05-オブジェクトと配列.md#5-配列のメソッド) |
| `SyntaxError`（`JSON.parse` で） | JSON の書式が正しくない。キーが `"` で囲まれていない、など | 中身を表示して形を確かめる。`try` ・ `catch` で受ける | [10](10-エラー処理とモジュール.md#2-エラーの種類) |

## 5. 非同期

| 症状 | 原因 | 直し方 | 章 |
|---|---|---|---|
| 結果が出る前に次の行が動く ・ 表示の順番が違う | 非同期の処理を待っていない | `await` で待つ ・ 続きを `then` の中に書く | [11](11-非同期.md#1-待たずに先へ進む) |
| 値ではなく Promise が返ってくる | `async` 関数はいつも Promise を返す | 呼ぶ側で `await` する | [11](11-非同期.md#5-async-と-await) |
| `SyntaxError: await is only valid in async functions and the top level bodies of modules` | `async` の付いていない関数の中で `await` を使った | 関数に `async` を付ける ・ 一番外側なら `.mjs` にする | [11](11-非同期.md#5-async-と-await) |
| `Uncaught (in promise) Error: …` | 失敗した Promise を誰も受けていない | `await` して `try` ・ `catch` ・ `.catch(…)` を付ける | [11](11-非同期.md#6-非同期のエラー) |
| `try` で囲んだのにエラーが捕まらない | エラーが起きたのは、`try` を抜けた後で動いた処理の中 | Promise にして `await` する | [11](11-非同期.md#6-非同期のエラー) |
| タイマーが時刻どおりに呼ばれない | 重い処理が流れを止めている | 重い処理を分ける ・ 短くする | [11](11-非同期.md#1-待たずに先へ進む) |
| 2 つの待ちに、合計の時間がかかる | `await` を 1 つずつ順に書いた | 関係が無ければ `Promise.all` | [11](11-非同期.md#5-async-と-await) |

## 6. ファイルとモジュール

| 症状 | 原因 | 直し方 | 章 |
|---|---|---|---|
| `ReferenceError: require is not defined in ES module scope, you can use import instead` | ES Modules のファイルで `require` を使った | `import` に書き換える | [12](12-CommonJSとESModules.md#2-書き方の比較) |
| `SyntaxError: Cannot use import statement outside a module` | CommonJS として読まれるファイルで `import` を使った | 拡張子を `.mjs` にする ・ `package.json` に `"type": "module"` | [12](12-CommonJSとESModules.md#3-拡張子と-type-の決まり) |
| 警告 `MODULE_TYPELESS_PACKAGE_JSON` | `"type"` の無い `package.json` の下で、`.js` に `import` を書いた | `package.json` に `"type": "module"` | [12](12-CommonJSとESModules.md#3-拡張子と-type-の決まり) |
| CommonJS から名前付きで `import` できない | Node.js が名前を見つけられない書き方だった | 既定の export として受けてから分ける | [12](12-CommonJSとESModules.md#4-お互いを読み込む) |
| あるはずのファイルが `ENOENT` で見つからない | パスはカレントフォルダから数えられる | `join(import.meta.dirname, …)` でスクリプトの場所から組み立てる | [12](12-CommonJSとESModules.md#5-__dirname-と-importmeta) |
| 読んだ行の末尾に見えない文字が付く | Windows の改行 `\r\n` の `\r` が残った | `split(/\r?\n/)` で分ける | [11](11-非同期.md#7-nodejs-でファイルを読み書きする) |
| `import` で見つからない（拡張子なし） | ES Modules は拡張子を省略できない | `"./math.mjs"` と拡張子まで書く | [10](10-エラー処理とモジュール.md#4-モジュール) |
