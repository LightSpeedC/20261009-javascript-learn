対象読者とゴール

  • 対象読者: Java ・ C# ・ VBA を少し触った初心者。変数・基本の文法・if ・ for ・ while ・ switch が分かる程度。関数・クラス・例外・非同期は知らない前提で書く
  • ゴール: Node.js で .js を書いてエラーを読んで直せる。型変換・this ・クロージャ・非同期の動きを自分のことばで説明できる
  • 次の一歩: 型を書ける TypeScript へ進める

章立ての意図

  • 2 部構成: 第1部（01〜13）は Node.js で言語そのものを学ぶ。第2部（14〜）はブラウザで DOM ・イベントを学ぶ
  • 山場は後半に 2 段で置く: 前半の山は 04（型変換）と 07（スコープ ・ this ・グローバル）。JavaScript らしい落とし穴を知る。後半の山は 09（クロージャ）と 11（非同期）。最も大事な仕組みで、ここを越えると実務のコードが読めるようになる
  • ハンズオンは各部の最後に宿題として置く: 勉強会の時間は読み合わせと短い演習に使い、まとまった作業は各自で行う
  • 付録は順に読まない: A1 逆引き ・ A2 Java ・ C# ・ VBA との対応表 ・ A3 落とし穴カタログは、困ったときに引く

勉強会の進め方

回範囲ねらい
第1回01〜06環境を動かし、値・型変換・関数に慣れる。01〜03 は読み流し、04 に時間を寄せる
第2回07〜08this ・グローバル変数・プロトタイプ（前半の山）
第3回09〜10クロージャ（後半の山）、エラー処理とモジュール
第4回11〜12非同期（後半の山）、CommonJS と ES Modules
宿題13ハンズオン。第2部の初回の冒頭で振り返る

1 回は 90 分。振り返りと質問 10 分 ／ 読み合わせ 50 分 ／ 演習 25 分 ／ 次回予告 5 分。

参加者には、事前に Node.js を入れて node --version が表示される状態にしておいてもらう（02 章）。

実行の仕組みと資料の作り方

「▶ 実行」ボタン

  • js/runner.js が、<div class="example" data-run="…"> で囲んだ例にボタンを付ける
  • data-run="worker" の例は、Web Worker（js/worker.js）の中で実行する。ページと別のスレッドなので、無限ループでも資料は固まらない。5 秒で打ち切る
  • 値の表示は js/inspect.js が作る。Node.js の console.log と同じ形になるように、Node の表示の決まりを写している
  • data-run="node" の例は、Node.js でしか動かないもの。Node.js で実行した結果を記録しておき、ボタンを押すと表示する
  • 例の中の pre.output が記録した出力。JavaScript が動かない環境（Markdown など）ではそのまま見える
  • ブラウザで動かすため、この 3 つのファイルはビルドの要らない JavaScript で書いている

資料を書き換えたら

  1. node tools/20_build/build-docs.ts で、前後のナビ ・ 目次 ・ 章の色 ・ 資料一覧を書き込む
  2. tools/40_test/run-tests.cmd でテストを流す。資料の例を Node.js で動かした結果と、ブラウザで「▶ 実行」を押した結果の両方を、載せた出力と比べる
  3. html2md --root . --dir docs --dir notes で Markdown を作り直す
