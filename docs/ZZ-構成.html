対象読者とゴール

  • 対象読者: Java ・ C# ・ VBA を少し触った初心者。変数・基本の文法・if ・ for ・ while ・ switch が分かる程度。関数・クラス・例外・非同期は知らない前提で書く
  • ゴール: Node.js で .js を書いてエラーを読んで直せる。型変換・this ・クロージャ・非同期の動きを自分のことばで説明できる。ブラウザで DOM とイベントを使った小さな画面を作れる
  • 次の一歩: 型を書ける TypeScript へ進める

章立ての意図

  • 2 部構成: 第1部（01〜13）は Node.js で言語そのものを学ぶ。第2部（14〜23）はブラウザで DOM ・イベント ・ フォーム ・ 通信 ・ 保存を学ぶ
  • Web でできることは紹介に留める: 20 〜 22 章は、描画 ・ メディア ・ リアルタイム通信 ・ ライブラリの埋め込みを、短い例で見せるだけにする。詳しく説明すると入門の範囲を超えるため
  • 山場は後半に 2 段で置く: 前半の山は 04（型変換）と 07（スコープ ・ this ・グローバル）。JavaScript らしい落とし穴を知る。後半の山は 09（クロージャ）と 11（非同期）。最も大事な仕組みで、ここを越えると実務のコードが読めるようになる
  • ハンズオンは各部の最後に宿題として置く: 勉強会の時間は読み合わせと短い演習に使い、まとまった作業は各自で行う
  • 付録は順に読まない: A1 逆引き ・ A2 Java ・ C# ・ VBA との対応表 ・ A3 落とし穴カタログは、困ったときに引く

実行の仕組みと資料の作り方

「▶ 実行」ボタン

  • js/runner.js が、<div class="example" data-run="…"> で囲んだ例にボタンを付ける
  • data-run="worker" の例は、Web Worker（js/worker.js）の中で実行する。ページと別のスレッドなので、無限ループでも資料は固まらない。5 秒で打ち切る
  • 値の表示は js/inspect.js が作る。Node.js の console.log と同じ形になるように、Node の表示の決まりを写している
  • 資料をファイルとして直接開いた（file://）ときは、Worker を作れないため、data-run="worker" の例も iframe で実行する。この場合は無限ループを書くとページごと固まる。fetch は file:// では使えないので、通信を使う例は理由を表示して止まる
  • data-run="dom" の例（第2部）は、HTML ・ CSS ・ スクリプトの組を iframe の中に置いて動かし、画面と console を見せる。console の受け渡しは js/frame.js が行う。ページと同じ流れで動くので、時間で打ち切れない
  • data-run="node" の例は、Node.js でしか動かないもの。Node.js で実行した結果を記録しておき、ボタンを押すと表示する
  • data-run="file" は、置いておくだけのファイル（読み込まれる側のモジュールや package.json）。ボタンは付けない
  • data-net="cdn" を付けた例は、CDN からライブラリを読み込む。テストを JSL_NET=0 で流すと、これらを飛ばす
  • 例の中の pre.output が記録した出力。JavaScript が動かない環境（Markdown など）ではそのまま見える
  • ブラウザで動かすため、js/ のファイルはビルドの要らない JavaScript で書いている

実行の制約

制約起きること
確かめたブラウザは Chromium だけFirefox ・ Safari では、エラーの文面や値の表示が載せた出力と違うことがある。出力とエラーの文面は Node.js ・ Chrome ・ Edge と同じ V8 のもの
値の表示は js/inspect.js による写しPromise の状態（<pending> など）や、エラーが起きた場所（スタック）は、Node.js と同じには出ない
第2部の例（data-run="dom"）は時間で打ち切れない無限ループを書くと、ページごと固まる。タブを閉じて開き直す
ネットワークが要る例がある20 〜 22 章の CDN を使う例と、18 章の通信の例は、オフラインでは動かない
ファイルとして直接開いた（file://）とき第1部の例も iframe で動くので、5 秒の打ち切りが効かず、無限ループで固まる。globalThis は self ではなく window になる（07 章）。fetch は使えない。エラーの内容をブラウザが隠すことがある。公開ページか、ローカルサーバー経由（14 章）で開けば、どれも起きない
3 桁区切りなどの書式は、実行する環境の言語設定に従うtoLocaleString() を言語の指定なしで呼ぶ例（04 ・ 10 ・ 13 ・ 15 ・ 17 章）は、日本語 ・ 英語以外の設定では区切りの記号が変わる
