値と文字列

したいこと書き方章
変数を作るconst x = 1;（入れ直すなら let）03
値の型を調べるtypeof x ・ 配列は Array.isArray(x) ・ null は x === null03
文字列に値を埋め込む`${name}さん`03
含まれているか調べるs.includes("abc")03
一部を取り出すs.slice(開始, 終了)03
区切りで分けるs.split(",") ・ 改行は s.split(/\r?\n/)03
置き換えるs.replace("a", "b")（全部なら replaceAll）03
前後の空白を除くs.trim()13
見た目の文字数を数える[...s].length03
文字列を数値にするNumber(s) ・ 先頭だけなら parseInt(s, 10)04
数値でないか調べるNumber.isNaN(n)04
3 桁区切り ・ 小数の桁をそろえるn.toLocaleString() ・ n.toFixed(2)04
切り捨て ・ 四捨五入Math.floor(n) ・ Math.round(n)03

配列

したいこと書き方章
末尾に足す ・ 取り出すarr.push(x) ・ arr.pop()05
含まれているかarr.includes(x)05
1 つずつ処理するfor (const x of arr) { … } ・ 番号も要るなら arr.forEach((x, i) => …)05
各要素を変えた配列を作るarr.map((x) => x * 2)05
条件に合うものだけ選ぶarr.filter((x) => x > 0)05
条件に合う最初の 1 つarr.find((x) => x.id === id)05
合計するarr.reduce((sum, x) => sum + x, 0)05
数値を小さい順に並べる[...arr].sort((a, b) => a - b)05
コピーする ・ つなげる[...arr] ・ [...a, ...b]05
重なりを除く[...new Set(arr)]（Set は同じ値を 1 つしか持たない入れ物）05
文字列につなぐarr.join(", ")05
配列の配列を 1 段にするarr.flat()13

したいこと書き方章

くり返し実行する ・ 止めるconst id = setInterval(f, ミリ秒) ・ clearInterval(id)09

結果を待つconst x = await f();（async 関数の中か .mjs の一番外側）11
複数を同時に待つawait Promise.all([f(), g()])11
