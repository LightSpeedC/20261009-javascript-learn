JavaScript 入門 学習資料

Java ・ C# ・ VBA を少し触った人のための JavaScript 学習資料・勉強会資料。Node.js の言語編とブラウザ編、ページ上で実行できるサンプル付き

📅 作成: 2026-10-09 / 更新: 2026-10-10

JavaScript の言語の仕組み（型変換・this ・クロージャ・非同期）と、ブラウザでの DOM ・イベントを学ぶ資料です。勉強会で 1 回ずつ読み合わせる形を想定しています。

資料一覧

本編は 01 から順に読みます。付録は、困ったときに引きます。各資料のコードは、横の「▶ 実行」ボタンでその場で動かせます。

  • 第1部 言語編01. 背景JavaScript がどこで生まれ、どこで動くのか。Java ・ C# ・ VBA と何が違うのかを、ざっと掴む
  • 第1部 言語編02. 実行環境Node.js を入れて、1 行ずつ試す方法と、ファイルに書いて実行する方法を身につける
  • 第1部 言語編03. 値と変数const と let の使い分け、7 種類のプリミティブ型、数値と文字列の性質、null と undefined
  • 第1部 言語編04. 演算子と型変換★ 前半の山。値が知らないうちに別の型へ変わる「暗黙の型変換」と、その落とし穴を避ける書き方
  • 第1部 言語編05. オブジェクトと配列データをまとめて持つ 2 つの入れ物。参照とコピーの違い、分割代入、配列のメソッド、JSON
  • 第1部 言語編06. 関数関数の 3 つの書き方、引数の既定値と残余引数、そして「関数は値である」ことを使ったコールバック
  • 第1部 言語編07. スコープ・this・グローバル★ 前半の山。変数が見える範囲、var の巻き上げ、グローバル変数の事故、呼び方で変わる this
  • 第1部 言語編08. クラスとプロトタイプclass 構文の書き方と継承。その裏で動いているプロトタイプの仕組み。Java ・ C# のクラスとの違い
  • 第1部 言語編09. クロージャ★ 後半の山（最重要）。関数が、生まれた場所の変数を覚え続ける仕組み。状態を隠す ・ 関数を作る関数 ・ ループの落とし穴
  • 第1部 言語編10. エラー処理とモジュールtry ・ catch ・ throw でエラーを扱う。ファイルを分けて import ・ export でつなぐ。npm の最小限
  • 第1部 言語編11. 非同期★ 後半の山（最重要）。待たずに先へ進む仕組み、イベントループ、Promise と async ・ await、ファイルの読み書き
  • 第1部 言語編12. CommonJS と ES ModulesNode.js にある 2 つのモジュール形式。require と import、拡張子 .cjs ・ .mjs ・ .js と package.json の "type"、古いコードの見分け方
  • 第1部 言語編13. ハンズオン宿題。家計簿の CSV を集計するコマンドラインのツールを、4 つの手順で作る。第1部で学んだことを 1 つにつなげる
  • 第2部 ブラウザ編14. ブラウザで動かす第2部の始まり。HTML から JavaScript を読み込む方法、開発者ツール、手元でページを開くためのローカルサーバー
  • 第2部 ブラウザ編15. DOM画面の部品を JavaScript から探し、書き換え、作って足す。HTML の木構造と、安全な書き換え方
  • 第2部 ブラウザ編16. イベントクリックや入力に反応する。イベントオブジェクト、伝わり方と委譲、既定の動きを止める、ハンドラの中の this
  • 第2部 ブラウザ編17. フォーム入力欄の値を読む、送信を止めて JavaScript で受け取る、入力を確かめる、入力に合わせて表示を変える
  • 付録A1. 逆引き「〜したい」から書き方を引く。詳しい説明は、右の列の章へ
  • 付録A2. Java ・ C# ・ VBA との対応表知っている言語の書き方から、JavaScript の書き方を引く。対応は目安で、細かい動きは違うことがある
  • 付録A3. 落とし穴カタログ「おかしい」と思ったときに、症状から原因と直し方を引く。エラーの文面は Chrome ・ Edge ・ Node.js のもの
