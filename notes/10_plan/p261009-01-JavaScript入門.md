## 1. 目的と全体像

### 対象読者とゴール

- **読者**: Java ・ C# ・ VBA を少し触った初心者。変数・基本の文法・`if` ・ `for` ・ `while` ・ `switch` が分かる程度。関数・クラス・例外・非同期は知らない前提で書く
- **ゴール**: Node.js で `.js` を書いてエラーを読んで直せる。型変換・`this` ・クロージャ・非同期の動きを説明できる。ブラウザで DOM とイベントを使った小さな画面を作れる
- 読み終えたら、公開済みの TypeScript 学習資料へ進める

### 構成

| 部 | 実行環境 | 章 | 勉強会（各 90 分） |
|---|---|---|---|
| 第1部 言語編 | Node.js | 01〜13 ＋付録 A1〜A3 | 第1〜4回 |
| 第2部 ブラウザ編 | ブラウザ | 14〜23 | 第5〜6回 |

各部の最後の章はハンズオンで、宿題にする。1 回の時間配分は、振り返りと質問 10 分 ／ 読み合わせ 50 分 ／ 演習 25 分 ／ 次回予告 5 分。

## 4. 作り方と未決事項

### 作り方

- 資料は `docs/` に HTML で置く（`01-背景.html` など）。共通 CSS は `docs/css/style.css`、サンプルは `docs/samples/`
- カラフルな SVG 図を多用する。各章に 1 点以上、山場の章は複数
- 「Java ・ C# ・ VBA から来た人へ」の枠で、読者の知っている言語との違いを補う
- コードは実際に動かしてから載せ、出力は実行結果を貼る。エラーは英語のまま載せて訳を添える
- サンプルコードは jsprimer（[https://jsprimer.net/](https://jsprimer.net/)）のように、資料のページ上で実行できるようにする（下の「サンプルコードの実行」）
- Node.js は v26 系の、資料を作る時点の最新版を使う。確かめた版は `node --version` の実測値を `docs/ZZ-構成.html` の 1 か所にだけ書く

### サンプルコードの実行

jsprimer は、GitBook のプラグイン js-console（codemirror-console）を使っている。コードの横のボタンを押すと、編集できるエディタ（CodeMirror）とコンソール風の出力欄が開き、ブラウザの中でコードを評価して `console.log` の出力とエラーを表示する。

| コードの種類 | ボタンを押したとき |
|---|---|
| ブラウザで動くもの（値・関数・クラス・クロージャ等） | その場で実行し、出力とエラーを表示する。コードは書き換えて再実行できる |
| タイマー・Promise ・ `async` ・ `await` | 同じく実行する。出力は時間差で順に追加されていく（11 章の例はこちらを多めにする） |
| Node.js でしか動かないもの（ファイルの読み書き・ディレクトリ一覧・`require` 等） | 実行はせず、Node.js で実際に動かしたときの出力を、あらかじめ記録したものとして表示する。「Node.js での実行結果」と明示し、書き換えはできない |

仕組みは自前で書き、`docs/js/` に置く。CDN は使わない。実行する場所は部で分ける。

- **第1部: Web Worker**。ページと別のスレッドで動くので、無限ループでも資料が固まらず、時間で打ち切れる。`console` を差し替えて出力を `postMessage` でページへ送る
- **第2部の DOM の例: iframe**。Worker には DOM が無いため
- Worker のグローバルは `window` ではなく `self`。07 章の例は実際に動かし、ブラウザ本体と結果が違えば本文で説明する
- `file://` で直接開いたときに Worker が動くかは未確認。動かなければ、ローカルサーバーで開くよう案内する

記録する出力は、`docs/samples/` のコードを実際に Node.js で動かして得る。
